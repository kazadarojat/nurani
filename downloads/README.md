# Unduh Rasa AI

- **Windows:** [RasaAI.exe](RasaAI.exe) — jalankan dengan klik dua kali. Memerlukan Microsoft Edge dan .NET Framework 4.5 atau lebih baru. Untuk keluar sepenuhnya, klik kanan ikon Rasa AI di area notifikasi Windows dan pilih **Keluar**.
- **Android:** [RasaAI-debug.apk](RasaAI-debug.apk) — versi uji untuk Android 8.0 atau lebih baru. APK ditandatangani dengan kunci debug dan belum diuji pada perangkat Android; fitur mikrofon belum terintegrasi dan unduhan/ekspor masih memerlukan penyesuaian.

Data dari localhost, GitHub Pages, aplikasi Windows, dan aplikasi Android disimpan terpisah. Gunakan cadangan untuk memindahkan data jika fitur ekspor dan impor pada perangkat mendukungnya. Kunci API perlu dimasukkan kembali.
